# Littlest Tokyo

`littlest-tokyo.glb` is "Littlest Tokyo" by [glenatron](https://sketchfab.com/glenatron), from
[Sketchfab](https://sketchfab.com/3d-models/littlest-tokyo-94b24a60dc1b48248de50bf087c0f042), from the three.js
examples, compressed with `gltfjsx --transform --keepnames --keepgroups` (WebP textures at their original size,
Draco geometry).
