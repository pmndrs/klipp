---
title: On-demand rendering
description: Render only while the camera is moving.
nav: 90
---

`klipp.update` returns `true` while anything is still moving (a blend, damping catching up, a shake), or the shot changed this frame. Render only then, and skip frames while the camera has settled.

Keep calling `update` every frame, even while nothing renders: it notices on its own when a target moves. A loop that stops calling `update` while idle starts again from `klipp.subscribeFrameRequest(listener)` and `impulseField.subscribeImpulses(listener)`, called whenever something changes through Klipp between frames.

```ts
function frame(dt: number) {
  if (klipp.update(dt) || sceneChanged) {
    engine.camera.setTransform(klipp.shot.position, klipp.shot.quaternion);
    engine.render();
  }
}
```

Klipp works with `<Canvas frameloop="demand">`: props, input, impulses and methods of cameras, pieces and axes ask for frames on their own. Call `invalidate()` only after a change Klipp can't see, like moving a target or setting a piece's field through its `ref`.

```tsx
const invalidate = useThree((state) => state.invalidate);

function onClick() {
  targetRef.current.position.set(0, 0, 5);
  invalidate();
}
```
