Sets the camera's `fov`, `orthographicSize`, `near` and `far`. Leave one out to keep the current value. Each one can be damped separately, for effects like a speed zoom. The `zoom` axis magnifies the view from input, for example with the mouse wheel.

Set lens values through `Lens`, not on the real camera directly. Klipp writes the lens every time the shot changes, so direct changes get overwritten, for example by the next blend.

## Settings

| Setting | Description | Default |
| ------- | ----------- | ------- |
| `fov` | Field of view, in degrees. | |
| `orthographicSize` | Half the view's height in world units, for an [orthographic camera](/api/klipp#orthographic-cameras). | |
| `near` | Near clipping plane. | |
| `far` | Far clipping plane. | |
| `fovDamping` | Seconds to reach a new `fov`. See [Damping](/getting-started/core-concepts#damping). | `0` |
| `orthographicSizeDamping` | Seconds to reach a new `orthographicSize`. | `0` |
| `nearDamping` | Seconds to reach a new `near`. | `0` |
| `farDamping` | Seconds to reach a new `far`. | `0` |
| `fovMaxSpeed` | Maximum `fov` change, in degrees per second. | `Infinity` |
| `orthographicSizeMaxSpeed` | Maximum `orthographicSize` change, in units per second. | `Infinity` |
| `nearMaxSpeed` | Maximum `near` change, in units per second. | `Infinity` |
| `farMaxSpeed` | Maximum `far` change, in units per second. | `Infinity` |
| `zoom` | Settings of the `zoom` axis, like `range`, `damping` or `recentering`. Later on, change them on `lens.zoom`. | see [Zoom](#zoom) |

## Zoom

`zoom` is an [`InputAxis`](/input/input-axis) holding the natural log of the magnification: `0` keeps the lens, `ln 2` (about `0.69`) shows the view twice as close. A pinch drives it one to one. It narrows `fov` and shrinks `orthographicSize`, also when `Lens` doesn't set them.

Set it as the [`zoomAxis`](/input/input-controller#mapping-a-source) of the drag that turns the camera, `lens.zoom` or `'zoom'` in React, and the camera turns slower while zoomed in.

| Axis | Range | Center | Wraps |
| ---- | ----- | ------ | ----- |
| `zoom` | `[0, ln 10]`, from `1×` to `10×` | `0` | no |

```ts
import { LensExtension } from '@pmndrs/klipp';

const lens = new LensExtension({ fov: 50, fovDamping: 0.4 });
camera.addExtension(lens);

// any time later
lens.fov = boosting ? 75 : 50;
```

**Zoom**

```ts
import { InputControllerDom } from '@pmndrs/klipp/dom';

const lens = new LensExtension({ zoom: { damping: 0.2 } });
camera.addExtension(lens);

const controller = new InputControllerDom({
  wheel: { axis: lens.zoom, gain: 0.001 },
  pinch: { axis: lens.zoom },
});
camera.whileOnScreen(() => {
  controller.connect(canvas);
  return () => controller.disconnect();
});
klipp.registerUpdate(() => controller.update()); // reads input before the cameras run
```

```tsx
<VirtualCamera name="chase" priority={10}>
  <Body.Follow target={carRef} offset={[0, 2, 6]} />
  <Aim.HardLookAt target={carRef} />
  <Extension.Lens fov={boosting ? 75 : 50} fovDamping={0.4} />
</VirtualCamera>
```

`ref` gives you the `LensExtension`. To change the lens every frame without re-rendering, set its fields directly:

```tsx
const lens = useRef<LensExtension>(null);

useFrame(() => {
  lens.current.fov = 50 + speed * 0.5;
});
```

**Zoom**

Add an [`<InputController>`](/input/input-controller) inside it to zoom with the wheel or a pinch:

```tsx
<Extension.Lens zoom={{ damping: 0.2 }}>
  <InputController wheel={{ axis: 'zoom', gain: 0.001 }} pinch={{ axis: 'zoom' }} />
</Extension.Lens>
```
